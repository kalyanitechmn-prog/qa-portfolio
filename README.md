# QA Portfolio - Junior QA Engineer

Hands-on software testing portfolio demonstrating manual testing, API testing, SQL data validation, and UI automation with Playwright.

## Projects

| Project | Focus | Tools |
|---|---|---|
| [Project 1 - Sauce Demo manual testing](project-1-manual-web/) | Test plan, 40 test cases, RTM, bug reports, summary report | Jira-style templates, Chrome DevTools |
| [Project 2 - API and data validation](project-2-api-and-data-validation/) | 20+ API checks, CRUD workflow, 20 SQL validation queries | Postman, SQLite |
| [Playwright regression suite](https://github.com/<YOUR-USERNAME>/playwright-saucedemo-tests) | Login, cart, and checkout automation with Page Object Model | Playwright, JavaScript, GitHub Actions |

## Skills demonstrated

- **Test design:** boundary value analysis, equivalence partitioning, decision tables
- **Test documentation:** IEEE 829-style test plan, test cases, traceability matrix
- **Defect reporting:** severity, priority, evidence, and reproduction steps
- **REST API testing:** status codes, payload validation, authentication, negative tests
- **SQL:** joins, aggregates, NULL handling, duplicate and orphan-record detection
- **Automation:** Playwright locators, web-first assertions, reports, CI

## Application under test

Project 1 and the Playwright suite use [Sauce Demo](https://www.saucedemo.com), a public demo store provided for testing practice. Project 2 uses [Restful Booker](https://restful-booker.herokuapp.com).
