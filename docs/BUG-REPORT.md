## Preconditions

Record starting data, permissions and settings needed to reproduce.

## Steps to reproduce

1. Record an exact action.
2. Include exact inputs and navigation.
3. Record the action that triggers the problem.

## Expected result

Describe the observable result and its requirement basis.

## Actual result

Describe what actually happened; quote error text exactly when relevant.

## User impact

Explain what is blocked or incorrect and whether a workaround exists.

## Evidence

Attach a screenshot or short video with device/build context. Add relevant logs only if collected. Remove personal data, credentials and unrelated information.

## Re-test after fix

Record fixed build, date, repeated steps, observed result and neighbouring regression checks. Preserve the original failure evidence.
