# QA Glossary & Key Concepts

## Testing Fundamentals

- **Quality Assurance (QA):** Process-oriented activities aimed at preventing defects during software development.
- **Quality Control (QC):** Product-oriented activities focused on identifying defects in the final software output.
- **Verification:** Evaluating work products (e.g., requirements, test plans) to determine if they meet specified conditions ("Are we building the product right?").
- **Validation:** Evaluating software during or after development to ensure it satisfies specified requirements ("Are we building the right product?").

## Test Types & Levels

- **Smoke Testing:** High-level validation of critical user workflows to verify build stability before deep testing begins.
- **Regression Testing:** Re-testing previously verified software features after code changes to ensure existing functionality remains unbroken.
- **Black-box Testing:** Test design technique where internal implementation/code is unknown to the tester.
- **Boundary Value Analysis (BVA):** Test design technique focusing on testing values at the extreme limits/boundaries of input ranges.
- **Equivalence Partitioning (EP):** Dividing input data into valid and invalid sets that are expected to be processed similarly.

## Defect Management

- **Severity:** The technical impact of a defect on the system (e.g., Blocker, Critical, Major, Minor).
- **Priority:** The business urgency for fixing a defect relative to product goals (e.g., High, Medium, Low).
- **Traceability Matrix (RTM):** Document mapping test cases directly to business requirements to ensure complete test coverage.
